# DEメTER Patches

Morphe patches bundle for YouTube, YouTube Music and Reddit — 1440p/4K downloads, glass miniplayer, DeArrow, native offline downloads for YouTube Music, and much more.

Patches by DEメTER. Based on Morphe Patches 2.3.0, licensed GPL v3.

## Add to Morphe

One tap on Android (Morphe Manager must be installed):

https://morphe.software/add-source?github=XDOTDEX%2Fdexter-patches

Or add it manually in Morphe Manager: **Sources → + → Remote**, paste this address and tap **Add**:

```
github.com/XDOTDEX/dexter-patches
```

Then select YouTube (or YouTube Music / Reddit), choose your patches and patch.
